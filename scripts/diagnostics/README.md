# Diagnósticos manuais do Supabase legado

Esses scripts não são necessários para iniciar o CRM. Eles consultam dados reais
e podem imprimir conteúdo de mensagens ou contatos.

Configure `NEXT_PUBLIC_SUPABASE_URL` e `SUPABASE_SERVICE_ROLE_KEY` somente no
ambiente do processo. Nunca grave credenciais nos arquivos ou no Git.

A chave que já esteve escrita nesses scripts deve ser rotacionada pelo responsável
do projeto Supabase, em coordenação com a aplicação atualmente publicada.
